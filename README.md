# Papago 多模型翻译评价助手

> 非官方开源项目，与 NAVER、Papago、DeepSeek 或阿里云无隶属或背书关系。使用前请确认你有权处理并向第三方模型发送相关图片与文字，也请遵守目标网站规则；自动评分结果应由人工抽查。

- v0.25.0 修复两类仍会停在“等待图片更新”的情况：页面已经切换且评分选项已清空，但图片 URL/页码标签延迟导致误判；以及评分完整但网络失败后“下一张/提交”按钮长期灰显。后台等待现在由扩展服务进程主动唤醒页面；评分清空可作为带延迟的新页证据。若同一张连续三次未切换，会重新写入已归档的本张分数，并仅在确认两个评分均完整时临时解除灰色按钮、从网页主环境重试提交。

- v0.24.0 修复评分已经填入、但评价页因网络卡顿或后台冻结没有真正切到下一张时连续任务长期停住的问题。扩展会在短时间内核对页码/任务标识；仍是同一张时重新触发已填表单事件，并通过扩展后台在网页主环境重试“下一张”。断网时保留评分等待恢复；页码已经变化时只等待图片稳定，不会重复点击。切换检测不再每 0.7 秒重新下载/解码高清图，只读取轻量资源指纹；高清原图仍在实际评分时读取一次，并带有小型内存缓存。

- v0.23.0 修复评价页被其他窗口遮挡、切到其他标签页或最小化后反复出现“后台截图失败”的问题。后台优先直接读取网页中的原图/译图资源，并从 DOM 的灰黄色区域与蓝色细框定位当前块；调试器截图降为非阻断兜底。下一张更新检测也改用网页图片指纹，不再持续依赖窗口合成截图。

- v0.22.0 合并 Luna 版的中英互译到原文件夹版本，并新增旧扩展 Edge/Chrome 归档一键迁移和 JSON 导入去重。界面移除不稳定的磁盘自动存档，只保留浏览器详细归档。连续运行遇到后台截图、页面切换或临时连接故障时会保持当前页自动重连；同一浏览器配置的并行任务最多同时发出两次模型请求，并加入随机退避，减少多个任务同步限流后一起停止。
- v0.20.0 新增英文→简体中文、简体中文→英文两个互译方向；沿用当前页面方向检测、原图高亮块定位、译图独立裁剪和评分规则，不改变已有日中、英日模式。

这是一个适用于 Microsoft Edge / Chrome 的 Manifest V3 扩展。它会截取 Papago Pro 当前任务中的原图与译图，可调用 DeepSeek 或阿里云百炼 Qwen3.8-Flash，分别给出翻译与渲染评分，填写评论，并可自动切换下一张。

## 安装

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择克隆或解压后的项目文件夹。
4. 打开或刷新 Papago Pro 评价页面。每次应用扩展源码更新后也要刷新一次已打开的 Papago 页面，让新版内容脚本重新注入。
5. 点击工具栏中的扩展图标，打开右侧面板。
6. 选择视觉模型并填写对应的 API Key，先点击“只评当前张”验证效果，再使用“开始连续评价”。

## 后续更新

扩展固定使用当前源码文件夹。后续源码更新完成后，打开扩展侧边栏并点击“应用本地更新”即可重新加载，不需要删除扩展、重新解压或重新安装。

## 开发与测试

```bash
npm install
npm test
```

`npm test` 运行不需要真实 API Key 或任务数据的静态与回归测试。浏览器归档和裁剪端到端测试可运行 `npm run test:e2e`；Windows 默认优先使用已安装的 Microsoft Edge，也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定浏览器。

项目不会把侧栏中保存的 API Key 或 IndexedDB 浏览器归档写入源码目录。提交前仍请检查截图、日志与导出文件，避免公开真实任务数据。

## 运行逻辑

- 每张只截取一次页面。“只评当前张”会保留你手动调整好的缩放和位置；连续模式才会复位到完整视图后识别高亮。
- v0.10.0 把原文和译文都改为独立定位。可靠蓝框可直接使用；颜色回退、候选冲突、小块或低置信度时，会让视觉模型先在完整图中返回坐标，再从网页原始图片裁出高清近景。不能再用原文坐标直接裁译文。
- 普通轮识别失败后会自动进入轻度、深度两级复核，并在后两轮加入四个重叠分块与对比度增强近景。这样可处理红色商品包装、手机底栏、竖排书页、很小的非正式文字以及与高亮色相近的背景；只有困难样本才增加调用量。
- 译图包含手机界面、缩放不同、文字位置移动时，也以整张译图为坐标基准定位；裁剪保留少量边距以容纳多行文字，评分模型再交叉检查是否选对块。网页原始图可用时，逐字识别使用原始图裁剪，而不是外层模糊截图。
- 侧栏提供可展开的“实际送评的译文近景”，可直接核对送给模型的区域。预览只保留当前张，不写入50条历史记录。
- 所选视觉模型按同一套内置评分规则返回翻译分、渲染分、评论和置信度。
- v0.10.1 将3分设为普通样本基准：明显较差优先给2，明显较好优先给4。普通结果限制在2到4分；只有模型给出明确逐字/排版满分证据并达到高置信度时才保留5分，只有完全错误或基本不可用且给出直接证据时才保留1分。未翻译、无结果等规则化特殊情况不受这一限制。
- v0.11.0 增加可选“后台取图”：Papago在前台时继续使用原有的可见标签页截图；切到其他标签页、Edge失去焦点或窗口最小化后，改用Chrome调试协议直接截取指定Papago标签页，不激活或切换页面。停止评价或45秒无取图后会自动断开。侧栏的运行状态和操作按钮移到设置上方。
- v0.12.0 增加严格按模型、阶段、复核轮次和全部输入图片指纹隔离的本地持久缓存。完全相同的原文定位、译文定位或评分在重复运行及后台服务重启后可直接复用；任一图片变化都会重新调用，避免串图。侧栏显示 DeepSeek 前缀命中率和本地免调用次数。此优化不减少图片、不降清晰度，也不取消疑难复核。
- v0.13.0 增加 `qwen3.8-flash` 选项，使用独立的千问百炼 API Key。默认接口为中国内地 OpenAI 兼容地址，也可填写百炼控制台给出的业务空间专属地址。千问请求会移除不兼容的图片 `detail` 字段、启用高分辨率视觉输入，并把稳定/轻度/深度模式映射到千问支持的推理档位；DeepSeek 原路径不变。
- v0.14.0 修复千问失败被误写成 N/A：API 鉴权、地域、限流、参数或响应错误现在会显示 HTTP 状态、错误码和 request_id，并停止当前标签页，不会填写评分；只有译图真实无结果/错误页连续两轮确认后才填 NA/NA。新增“测试当前 API”按钮，以很小的文本请求检查当前密钥、模型和接口地址。
- v0.14.0 同时把运行状态、控制按钮、近景预览和评价记录按 Edge 标签页隔离。每个任务启动时会固定自己的模型、接口、评价模式和评论模式；在另一个标签页更换模型或启动第二个任务，不会让第一个任务中途换模或把状态、评分、停止指令串到另一页。切换 Papago 标签页后，侧栏会自动显示并控制当前页的独立运行状态。
- v0.14.1 对 HTTP 408/429/500/502/503/504、服务暂不可用和网络连接中断进行最多两次退避重试；密钥、权限和参数错误不会重试。重试期间不填写页面，全部失败后保留最后一次 request_id 并停止，避免把接口故障误判成 N/A。
- v0.15.0 新增“翻译方向”选项：默认继续使用原来的“日文原文 → 简体中文译文”，也可以切换到“简体中文原文 → 日文译文”。原模式继续使用原来的评分提示词；新模式使用独立的语言约束、未翻译判断和缓存键。启动时还会核对网页顶部的 `JA → ZH_CN` 或 `ZH_CN → JA`，方向不一致会在截图和 API 调用前停止。
- v0.15.1 加强后台连续运行：启动后台取图时会立刻连接当前 Papago 标签页、临时禁止自动丢弃，并以浏览器后台计时器替代被遮挡页面中容易降频的等待计时；运行期间还会定期尝试把页面生命周期恢复为活动状态。停止或报错后会断开连接并恢复标签页原来的自动丢弃设置。后台页面更新较慢时最多等待50秒，前台仍保持原来的25秒和原截图路径。
- v0.15.2 将语言方向改为“当前页面强制锁定”：侧栏只绑定当前正在看的 Papago 标签页，每次启动都会重新读取该页顶部的 `JA → ZH_CN` 或 `ZH_CN → JA`，并自动选用对应规则；无法读取时直接停止，不再默认回退日译中。评价记录新增翻译方向、模型、状态、识别原译文、判断依据和取图方式；旧记录会明确显示“方向未记录”。
- v0.16.0 新增英日互评：支持 `EN → JA`（英文原文→日文译文）和 `JA → EN`（日文原文→英文译文）。四种语言方向都从当前页面顶部自动检测并强制锁定，分别使用独立提示词、未翻译判断和缓存键；检测不到或方向异常时在截图与API调用前停止。
- v0.17.0 新增本机长期详细归档。侧栏的快速记录仍只保留最近50条；每次完成评价还会把账号标签、任务编号、页面序号、语言方向、模型、识别原译文、评分、评论、判断依据、取图方式和时间写入独立的 IndexedDB，长期归档不随侧栏记录清空。账号标签由用户设置，任务编号和页面任务代码自动读取，运行开始后固定到该任务。侧栏可以导出按“账号→任务”分组的HTML审查报告或JSON备份。归档不保存图片和API Key；卸载扩展会删除浏览器内数据库，因此应定期导出。
- v0.18.0 将页面顶部的任务编号（例如 `E2600132`）设为归档主任务号，同时保留网址中的 `5221/3184` 作为网页任务路径；翻译方向继续以页面顶部标签为准。新增真实磁盘自动备份：用户在侧栏选择一次文件夹后，每完成一条就同步写入 IndexedDB，并按“账号名称/任务编号”追加到 `评价明细.jsonl`，另写入 `任务信息.json`。默认启用“磁盘未成功备份时暂停”，开始前会做写入测试，运行中写盘失败会在切换下一张前暂停。浏览器重启、网站退出和扩展正常更新不会删除外部磁盘文件；即使浏览器内数据库因卸载或配置损坏丢失，磁盘副本仍独立保留。
- v0.19.0 修复多任务串状态和串备份目录：账号名称、文件夹授权及备份句柄改为按“网址任务路径＋顶部任务编号＋语言方向”隔离，第二个页面选择新目录不会覆盖第一个页面正在使用的目录。切换标签页或同一标签页切换任务时，侧栏会重新读取当前页上下文，不再展示上一任务的结果；新任务必须重新填写账号名称。为避免误用v0.18的全局目录，升级后每个任务需要各自重新选择一次备份文件夹；原有磁盘文件不会删除，选择原目录即可继续追加。侧栏与内容脚本版本不一致时会要求刷新页面并阻止启动，避免扩展已更新但网页仍运行旧脚本。
- v0.19.2 修复绿色“可写”状态下点击“更换自动备份文件夹”仍复用原目录、没有弹出选择器的问题；可写时点击会立即选择新目录，权限异常时才优先恢复旧目录。
- v0.19.1 修复 Edge 文件夹权限的假失败：后台不再仅凭可能暂时回落为 `prompt` 的查询结果停止，而是以真实写入测试为准；只有文件系统实际拒绝写入才暂停。已有任务句柄可在侧栏按钮中直接重新授权，不必重新选择路径。顶部任务号扫描扩展到可见DOM、Shadow DOM、ARIA和含空格/零宽字符的编号，避免明明显示 `E2600132` 却只归档为网址路径。
- 评分指南已压缩成固定系统规则前置给所选模型，不会上传或重复阅读 62 页 PDF。翻译只识别和评价当前高亮文本块及其对应译文；完整图仅用于定位、场景和渲染上下文。高亮定位优先识别灰黄色半透明块和蓝色细框，避免把商品底色、按钮、输入框、道路或其他相似色块当成高亮。
- 高亮识别采用两级结构：优先寻找“灰黄色半透明内部＋蓝色细边框”的闭合或近闭合区域，通过横线配对、四边覆盖率和内部颜色共同判定；只有找不到可靠边框时才使用颜色连通域回退。压缩造成蓝框断点时会重建完整矩形，不再把某一段蓝线或相似色块当成文本块。
- 原文蓝框候选必须具有足够的灰黄色内部覆盖，颜色回退排除细长竖向区域。原文高清裁剪与带框截图进行局部相似度校验，未通过时保留带框截图。译文采用独立定位裁剪。
- 竖版图片会同时按 `object-fit` 的真实渲染尺寸和截图中的背景留白重新校准边界，不再把左右黑边算进坐标。圆形或很小的黄色气泡会使用像素边距生成紧凑局部，并禁用高风险的网页坐标裁剪，避免串到附近未高亮的大气泡。
- 网页高清局部的校验提高到 64 像素并同时比较颜色和文字边缘；不能再用过粗的 24 像素平均色相似度把错误气泡判成“0.95 一致”。
- 项目带有独立高亮检测回归测试，覆盖大黄色干扰块、小圆气泡、竖向道路色块、多蓝框竞争、断裂三边框、竖图黑边和满宽图片，后续修改必须一起通过。
- 返回 JSON 不再要求额外的翻译问题与渲染问题数组，避免重复描述并减少输出额度。
- 评论输出可选“中韩双语”“仅中文”或“不生成评论”。双语模式在 Papago 页面填写韩文；仅中文和无评论模式会清空页面的可选评论框，以减少输出额度。
- 侧栏保留当前标签页最近一次完成结果，记录栏默认只显示该标签页最近 2 条，可展开其余记录；全部标签页合计最多保存 50 条，第 51 条写入时自动删除最旧一条。
- 视觉定位或评分返回空内容、低置信度、文字缺失时会自动换用下一档思考与增强图复核，不再因第一轮空结果立即停住。API 密钥失效、余额不足等不可恢复错误仍会停止。
- 请求明确启用 JSON 输出；兼容标准 Chat Completions、意外的 SSE 分块和 Responses 风格正文。异常响应会显示 HTTP/字段结构诊断，不再被吞成“未知”空对象。
- 调用前检查四张图片的请求体大小，接近官方 48 MiB 限制时直接停止，不消耗一次无效请求。
- 完全相同的任务与图片会复用本地定位和评分结果，最多保存 120 条；首次出现的新图片仍需正常调用 API。平台前缀缓存是否命中由服务端决定，本地统计按 API 返回的缓存 token 计算。
- “稳定连续”关闭显式思考并保留 2200 token 给完整 JSON，适合批量运行，不会因 reasoning_content 先耗完长度而没有正文。“轻度思考”使用低强度和 10000 token，“深度分析”使用高强度和 20000 token，二者只建议单张；“极速省量”进一步压缩输出。
- 明确未翻译时自动填“翻译1、渲染NA”；译图显示“无结果/결과 없음”、错误页或确实没有生成结果时自动填“NA/NA”。多轮仍只能确认有内容但读不清或无法可靠对应时，用3/3中间档兜底并继续，避免与平均分产生过大偏差。兜底结果会在侧栏标明取图与复核情况。
- 要求模型先返回识别到的当前原文和实际译文；日→中与中→日分别使用对应的语种约束，避免仅凭低清预览误判文字语种或滥用NA。
- 扩展自动勾选两项评分并写入评论。
- 开启连续运行后，正常结果仍按置信度阈值控制；规则化NA、未翻译和3/3自动兜底不会卡住连续运行。
- 连续切换时会分别跟踪原图和译图，同时比较后台截图与网页图片节点。即使进度数字更新较慢或调试器截图暂时失败，只要页面图片已更新并稳定即可继续；一侧先更新、另一侧仍是旧图时仍会等待，避免串图。
- 定位返回和评分返回之后都会检查任务序号及停止状态，切页后丢弃旧结果；禁止同时启动单张与连续评价。
- 新一张开始分析或发生错误时会清空侧栏中的上一张结果，避免把旧评论误认为当前返回值。
- 扩展只识别并点击类名为 `btn_step_next` 的“下一张”按钮；遇到“提交、完成、结束”会停止。

## 注意

- Edge 的 `captureVisibleTab` 从侧边栏启动时不会稳定获得临时 `activeTab` 授权，因此扩展声明了 `<all_urls>` 截图权限；内容脚本仍只在 `papago-pro.naver.com` 运行，并且只截取当前可见标签页。
- “后台取图”默认关闭，并以清单中必需的 `debugger` 权限实现（该权限不能作为运行时可选权限申请）。Edge加载扩展时会显示权限确认；开关只控制是否使用。权限只用于当前运行中的Papago标签页：截图、阻止自动丢弃并在后台时维持活动；不会连接其他网页。若Papago页同时开着开发者工具，后台取图会提示关闭开发者工具，因为一个标签页不能同时被两个调试器连接。
- API 图片会发送给当前选择的 DeepSeek 或阿里云百炼千问；请确认任务数据允许使用第三方模型处理。
- API Key 仅保存在 `chrome.storage.local`，不会写入网页或项目文件。
- 浏览器详细归档按 Edge/Chrome 用户配置独立保存。卸载扩展会删除该配置下的归档，因此删除旧扩展前要先使用“一键合并旧版本归档”或导出 JSON，再在原版本导入。
- 页面结构发生变化时，扩展会停止并提示，不会盲目点击。
- 建议先用 3–5 张与人工评分对比，再调整置信度阈值。
