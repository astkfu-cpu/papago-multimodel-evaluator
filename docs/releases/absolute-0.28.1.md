# Absolute evaluator 0.28.1 — packaged release 2026-10-21

Formal release of the existing maintained absolute-scoring module. Runtime source is unchanged in this release. Includes independent source/target positioning, progress/image consistency checks, persistent archive and API cache isolation. Historical work is documented in CHANGELOG and ABSOLUTE_HISTORY; no development dates are backdated.

Unzip and load the extension folder. Update by overwriting the existing installation directory and reloading; back up first and do not uninstall. Plugin code is MIT and free; users configure and pay for their own API. The public pairwise module is a separate extension with different evaluation criteria.

Package SHA-256 and source-file hashes are in the attached releases.json.
