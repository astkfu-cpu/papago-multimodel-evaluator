# Self-contained public demo 1.0.0 — 2026-10-21

Self-authored image cards and evaluation page, distributed without customer task data. Unzip and open index.html in Edge/Chrome. The built-in simulated analysis runs offline without an extension or API key, uses predefined results and is explicitly marked as simulation. It is not a model accuracy benchmark.

Eight workflow items repeat two direction-specific source cases. Users can check independent translation/rendering choices, navigation, automatic local progress and demonstration exports. For real analysis, separately load the pairwise public extension and configure your own API key; real calls incur your API charges.

See the included README for steps, limitations and MIT license. Package SHA-256 is in releases.json.
